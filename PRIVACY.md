# Privacy

Display Profiles does not collect, store or send any personal information, and it has no network features.

- **What it stores.** Your display profiles and settings are saved in a file on your PC
  (`%APPDATA%\DisplayProfiles\profiles.json`). They contain monitor names, hardware IDs, resolutions and positions. The file
  never leaves your PC, and removing the app does not upload or share it.
- **What it reads.** It asks Windows which displays are connected and whether the PC is in Xbox mode, so it can switch layouts.
- **Xbox Game Bar widget.** The widget only reads a copy of your profile names that the app writes into the package's own
  folder on your PC.
- **No accounts, no analytics, no advertising, no telemetry.**

If you install the app from the Microsoft Store, Microsoft's own store and update services apply to the download, as for any
Store app; the app itself adds nothing.
